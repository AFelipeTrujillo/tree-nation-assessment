Tree Nation API

Available endpoints:

  • GET /api/health
  • GET /api/customers/{customerId}/stats (example with cus_002 id)
  • GET /api/analytics/visits-per-hour
  • GET /dashboard.html
  • POST /api/visits 
                    curl -X POST http://localhost:8080/api/visits \
                -H "Content-Type: application/json" \
                -d '{
                    "eventId": "device-event-abc-123",
                    "customerId": "cus_123",
                    "shopId": "shop_001",
                    "occurredAt": "2026-05-29T10:15:00Z"
                }'
